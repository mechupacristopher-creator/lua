# Eze Hub — PING A PONG

Auto play hub for [PING A PONG](https://www.roblox.com/games/80454787540545/).

## Loader

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mechupacristopher-creator/lua/main/PAP/pap_hub.lua"))()
```

Toggle the panel with **RightControl**.

## Features

**Auto Play**
- Auto Hit: returns every ball at full power, aimed at the corner away from your opponent, curving the other way each hit
- Shot settings: spin (Topspin, Drive, Chop), power, aim width, curve
- Auto Move: walks you to where the ball will land and dashes when it is far
- Auto Serve: walks behind the table into the serve box and serves at full power
- Auto Ability (E) and Auto Ultimate (F)
- Move Speed slider

**Farm**
- Auto Queue (Bot Match, 1v1 Duel, 2v2 Team, Mayhem)
- Auto Use Free Spins
- Redeem code RELEASE

## Notes

- Everything starts **off**.
- Running the script again replaces the previous copy.
