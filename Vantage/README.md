# Eze Hub — Vantage

Combat hub for [Vantage](https://www.roblox.com/games/9818210203/). Run it inside a match.

## Loader

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mechupacristopher-creator/lua/main/Vantage/vantage_hub.lua"))()
```

Toggle the panel with **RightControl**.

## Features

**Combat**
- Silent Aim: bullets go to the closest visible enemy in the FOV circle
- Aimbot: Always / Right Mouse / Left Mouse, Head or Torso, FOV radius, smoothing, wall check, FOV circle; works scoped with snipers
- Triggerbot with delay
- No Recoil, No Spread

**Visuals**
- ESP: highlight, name, health, distance, team check

**Player**
- Speed Boost with multiplier
- Bunny Hop (hold Space)

## Notes

- Everything starts **off**.
- Running the script again replaces the previous copy and keeps the toggles you had on.
